# Pizzaria Fornatta

Trabalho da disciplina de Análise e Projeto Orientados a Objetos.

Equipe: João Victor Seki Mantovani, Tiago, Rudson, Rafael Alves

## Sobre

Programa de terminal que simula o atendimento da Pizzaria Fornatta no
salão: mesas, pedidos, cozinha, caixa e estoque.

## Stack

Python 3, sem bibliotecas externas.

## Estrutura

- `pizzaria/` — uma classe por arquivo (Mesa, Pedido, Produto, Categoria,
  Garcom, Pagamento, Cozinha, Caixa, Estoque)
- `dados_iniciais.py` — carga inicial de categorias, produtos, mesas e
  garçons
- `main.py` — menu de terminal

## Como rodar

```
python main.py
```
